## Portfolio Scope

### Forestry and Environment

The forestry profile highlights experience in:

- Forest inventories and stand characterization
- Silvicultural management
- Agroforestry systems
- Botany and species identification
- Environmental characterization
- Conservation and fieldwork
- Scientific and technical publications

### Geospatial Analysis

The GIS profile includes work related to:

- Territorial and watershed analysis
- Remote sensing
- Raster and vector processing
- Spatial data preparation and quality control
- Terrain and morphometric analysis
- Environmental and risk mapping
- Reproducible geospatial workflows
- Python-based automation
